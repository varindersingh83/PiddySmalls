# Piddy Smalls

A gentle, game-like phonics starter for a three-year-old. The first loop is intentionally small: hear a word, identify its first sound, get immediate encouragement, and move to the next round.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL on a phone or iPad. Safari can use **Share → Add to Home Screen**.

## Product principles

- No timer, lives, ads, or shame-based feedback.
- Large touch targets and one decision at a time.
- SpeechSynthesis makes the prototype playable without a backend or audio asset pipeline.
- Progress is a tiny celebratory signal, not a performance score.

This is an early scaffold, not a claim that the learning sequence is research-validated. The next step should be testing with a parent and child before expanding content.
